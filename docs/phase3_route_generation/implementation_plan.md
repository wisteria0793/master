# [UPDATE] フェーズ3 推薦ロジックの改善: 空間コンテキストの考慮

## 概要と目的
先生のご指摘の通り、「半径内の単純な多数決」や「単なる上位K個の多数決」では、面積の大きい（数の多い）クラスタが常に有利になり、局所的な小さなクラスタが飲み込まれてしまうリスクがあります。

そこで、この問題を解決しつつ空間を考慮するために、**「距離重み付きのK近傍法（Distance-weighted KNN）」** を提案します。

## Proposed Changes

### [MODIFY] `src/urban_analysis/prototype/phase3_recommender.py`
POIの景観クラスタ (`ls_cluster`) を計算するロジックを以下のように更新します。

1. **上位K個の検索 (k-Nearest Neighbors)**: 
   KDTreeを用いて、各POIの座標から最も近い **上位 K個（例: K=5〜10）** の景観ポイントを取得します。
2. **距離による重み付け投票 (Distance-weighted Voting)**: 
   取得したK個のポイントに対して、単純な多数決ではなく **「POIからの距離の逆数 $1 / (距離 + \epsilon)$」** を重みとして各クラスタに投票します。
3. **最大スコアの採用**: 
   最も重み合計スコアが高かったクラスタを、そのPOIの景観クラスタとして採用します。

**この手法のメリット**:
- 空間的なコンテキスト（周囲の複数ポイント）を考慮できる。
- POIのすぐ近くに「小さなクラスタ」が存在する場合、距離が近いため重みが非常に大きくなり、周囲の「大きなクラスタ」に飲み込まれずに正しく判定されやすくなる。
