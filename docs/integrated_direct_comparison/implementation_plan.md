# 実験18.10: 統合アプローチの5パターン比較（シード vs ダイレクト / GNNあり vs なし）

## 目的
「POI-GNNによる事前学習」の効果と、「シード分類による情報の抽象化」の効果を多角的に検証するため、5つのパターンを同一条件下で比較する。

## 比較対象の定義（5パターン）

### カテゴリ1: シードベース (中間クラスタリングあり)
- **パターンA**: POI-GNN埋め込みに基づくシード(10) + 景観シード(10)
- **パターンB**: POI生データに基づくシード(10) + 景観シード(10)

### カテゴリ2: 直接統合 (中間クラスタリングなし)
- **パターンD [New]**: **POI-GNN埋め込み(64d)** + **景観生データ(768d)** を直接統合
- **パターンE [New]**: **POI生データ(799d)** + **景観生データ(768d)** を直接統合
- **パターンC**: (パターンEと同一の設定) ※過去の検証結果として保存

## 変更・追加ファイル

### [MODIFY] [compare_districts_abc.py](file:///Users/atsuyakatougi/Desktop/master/src/urban_analysis/gnn/compare_districts_abc.py)
A, B, C, D, E の5つの出力を生成するように拡張。

## 実装の詳細
1.  **入力の多様化**:
    - `run_pattern_direct` 関数を拡張し、POIの入力次元が 64(GNN) か 799(Raw) かを切り替えられるようにする。
2.  **データの読み込み**:
    - `residual_embeddings.csv` (POI-GNN埋め込み) を追加で読み込む。
3.  **地図の出力**:
    - 5つの HTMLファイルを生成。

## 検証ポイント
- **A vs D**: シード化（情報の要約）が地区境界の安定性にどう寄与しているか。
- **D vs E**: 統合前のPOI-GNNによる事前学習（空間平滑化）がある場合とない場合で、最終的な地区の質がどう変わるか。
