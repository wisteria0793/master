# 修正内容の確認 (Walkthrough): 実験18.10 A/B/C/D/E 五者比較の実装

## 実施内容
統合手法の決定的な比較を行うため、シードベースと直接統合、さらにPOI-GNNの有無を組み合わせた5パターンを一括実行するシステムを実装しました。

### 1. スクリプトの拡張
- `src/urban_analysis/gnn/compare_districts_abc.py` をさらに拡張し、A, B, C, D, E の5つの独立したロジックを実装しました。
- シードなしパターン（D, E）では、異次元入力を32次元の潜在空間に投影してから空間平滑化を行うプロジェクションGNNを導入しました。

### 2. 比較パターンのマトリクス
| パターン | POIデータ | 景観データ | 粒度 (Seed/Direct) |
| :--- | :--- | :--- | :--- |
| **A** | POI-GNNシード | 景観シード | Seed (10+10) |
| **B** | Raw-POIシード | 景観シード | Seed (10+10) |
| **D** | **POI-GNN埋め込み(64d)** | **景観Raw(768d)** | **Direct** |
| **E** | **Raw-POI(799d)** | **景観Raw(768d)** | **Direct** |
| **C** | (Eと同じ) | (Eと同じ) | Direct |

### 3. 出力結果
- [/docs/results/comparison_approach_abc_de/](../../docs/results/comparison_approach_abc_de/) 内に5枚の地図を出力しました。

## 検証結果の示唆
- シードベース（A, B）は地区のまとまりが強く、広域的な特徴を捉えやすい一方、直接統合（D, E）は地点ごとの個別性がより強調された結果となります。
- POI-GNNを通したパターン（A, D）は、空間的な文脈が事前に考慮されているため、通さないパターン（B, E）に比べて地区の境界がより都市構造（歴史的背景など）に適合しやすい傾向が期待されます。
