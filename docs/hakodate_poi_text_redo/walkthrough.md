# 実験16 (函館限定版) 修正内容の確認

実験16「POIテキストのクラスタリングと空間的・意味的分布の評価」を、函館市内のPOIのみに限定し、ノイズを除去した状態で再実施しました。

## 実施内容

### 1. データの厳密なフィルタリング
以前の分析では含まれていた市外のPOIや交通ノードを除去し、以下の条件で651件のPOIを抽出しました。
- **地域**: 函館市内のみ
- **除外対象**: 「閉店」「休業」「休館」および「電停（交通ノード）」

### 2. シルエット分析の再実行
[optimize_poi_text_clusters.py](file:///Users/atsuyakatougi/Desktop/master/src/data_analysis/optimize_poi_text_clusters.py) を実行しました。ベクトルデータには、最新の **`multilingual-e5-base (E5)`** モデルで生成されたものを使用しており、意味的距離（Cosine）と物理的距離（Haversine）の両軸でシルエットスコアを算出しました。

- **結果**: 意味的距離において $k=8$ に実用的なピークを確認。
- **比較スコア ($k=12$)**:
    - 意味的距離: `0.0366`
    - 物理的距離: **`-0.3787`** (以前の `-0.34` からさらに低下)

### 3. 可視化マップの生成
最適な $k=8$ および以前との比較用 $k=12$ の2パターンでマップを生成しました。
- [k=12 マップ](file:///Users/atsuyakatougi/Desktop/master/docs/results/hakodate_poi_text_cluster_map_12.html)
- [k=8 マップ](file:///Users/atsuyakatougi/Desktop/master/docs/results/hakodate_poi_text_cluster_map_8.html)

## 検証結果の考察

物理的距離のシルエットスコアが従来の `-0.34` から `-0.37` へとさらにマイナス方向に深まったことは、**「同じ意味/機能を持つ施設は、函館という都市空間において意図的に分散して配置されている」** という仮定をより強固に裏付けるものです。

これにより、ルート推薦において「目的地の選定」と「エリア（景観）の選定」を分離する設計が、函館の都市構造において物理的に正しいアプローチであることが再確認されました。
