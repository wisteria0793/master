# Walkthrough: Phase 5推薦エンジンへの景観目的関数の追加

## 実装した内容

ユーザーからの要望に基づき、多目的最適化によるルート推薦（Phase 5）に「景観の良さ（NKDE近似による空間密度スコア）」を4つ目の目的関数として追加しました。

### 1. `phase5_recommender.py` の更新
*   **景観スコアの動的計算**: Phase 4の候補フィルタリングで抽出されたPOI（起点と同じ景観クラスタに属するPOI）に対し、該当景観クラスタのポイント密集度を **Quartic Kernel（半径500m）を用いたカーネル密度推定（KDE）** によって計算するようにしました。
*   **目的関数の4次元化**: 計算したスコアを正規化（`norm_ls_density`）し、目的関数 `_objective_function` に組み込みました。これにより、NSGA-IIIは「移動距離」「評価」「レビュー数」「景観スコア」の4つを同時に最適化するようになります。
*   **重みと参照点の調整**: デフォルトの重みを `距離: 0.4, 評価: 0.2, レビュー数: 0.2, 景観: 0.2` に再設定し、NSGA-IIIの参照点生成関数（`get_reference_directions`）を4次元（`n_dim=4`, 参照点数120個）に対応させました。

### 2. ドキュメント（`README.md`）の更新
*   Phase 5の解説セクションにて、4つの目的関数による同時最適化が行われること、および直線距離を用いたカーネル密度推定による近似値が使用されている旨を追記しました。
