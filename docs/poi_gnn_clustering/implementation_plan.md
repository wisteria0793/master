# POI GNN埋め込みのクラスタリングと地図プロットの実装計画

生成した GNN 統合埋め込みベクトル (`poi_gnn_embeddings.npy`) を用いて、都市構造や施設特性を反映したクラスタを抽出し、地図上に可視化します。

## ユーザーレビューが必要な事項

> [!IMPORTANT]
> - 最適なクラスタ数の算出には、既存の `optimize_poi_text_clusters.py` と同様に **シルエットスコア (Silhouette Score)** を使用します。
> - クラスタリング手法は、プロジェクト内で一貫して使用されている **Ward法（階層的クラスタリング）** を採用します。

## 提案される変更

### 1. クラスタ分析・可視化スクリプトの作成
最適なクラスタ数の探索から、最終的な地図プロットまでを一括して行うスクリプトを作成します。

#### [NEW] [analyze_poi_gnn_clusters.py](file:///Users/atsuyakatougi/Desktop/master/src/urban_analysis/gnn/analyze_poi_gnn_clusters.py)
- **データロード**: `poi_gnn_embeddings.npy` と `filtered_facilities.json` (座標・名前等) をロード。
- **最適クラスタ数の算出**: $k=5$ から $40$ 程度の範囲でシルエットスコアを計算し、最も高いスコアを示す $k$ を特定します。
- **クラスタリング実行**: 特定された最適な $k$ を用いて Ward 法でクラスタ分割を実行。
- **地図プロット**: `folium` を使用し、クラスタごとに色分けされた POI を地図上に表示する HTML ファイルを生成します。

### 2. 結果の保存
- **統計グラフ**: クラスタ数とシルエットスコアの関係を示すグラフを保存。
- **クラスタ結果**: 各 POI にクラスタ ID を付与した CSV を保存。
- **インタラクティブマップ**: ブラウザで閲覧可能なクラスタマップを保存。
